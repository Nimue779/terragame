This project is an HTML and JS text RPG game based in space that you can play in your browser. To play, all you have to do is read the text prompt and click on the option you like best. There is audio for clicking buttons, using items, and background music.

Every 3 seconds, oxygen will tick down, so throughout the game you have to find and use Oxygen Canisters. The aim of the game is to reach the escape shuttle and escape the Astraea.
