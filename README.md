This project is an HTML and JS text RPG game based in space that you can play in your browser. To play, all you have to do is read the text prompt and click on the option you like best. There is audio for clicking buttons, using items, and background music. Every 3 seconds, oxygen will tick down, so throughout the game you have to find and use Oxygen Canisters. The aim of the game is to reach the escape shuttle and escape the Astraea. 

I have coded part of this project whist on an ice hockey tournament using hotspot and terrible camp wifi, so this project was frustrating. I have used Gemini in parts of this game because I have not used Java Script before now. I used Gemini to help me debug, because Java Script is very particular about capitals and I can't spell. I also used Gemini to help me learn the language, but I wrote all of the code myself. 

Throughout this project, I had many issues with spelling errors and missed capital letteres that led to my entire game breaking. I also had issues with the inventor system, because it would not remove items once they had been used, or it would never add the item in the first place.
